## Este é o meu Sistema de controle de projetos
## O codigo está em java (ainda n versionado).


1. Instale o MySql
2. Execute o script no arquivo txt, e execute em cada linha
3. Instale e abra o Eclipse
4. Abra o Eclipse, vá em arquivos e importe o arquivo Sistema__controle_projetos
5. Vá para a Classe application.proporties e mude o hoost e a senha (Ambos sção o hoost  esenha do seu MySql respectivamente)
6. Execute o arquivo Main no Eclipse
7. Abra o Swagger no navegador
8. Pronto 😄

```bash
python jogo_da_velha.py
```

## Jogo da Velha em C

Para compilar e executar no terminal (Linux, WSL ou Git Bash):

```bash
gcc jogo_da_velha.c -o jogo
./jogo
```
Em windons:
```bash
gcc jogo_da_velha.c -o jogo.exe
jogo.exe
```

Se vc já tiver um compilador, é so abrir o arquivo com ele.
